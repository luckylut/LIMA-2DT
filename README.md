# LIMA-2DT
### Páginas de Filmes

Nesse projeto, desenvolvi uma página de filmes utilizando **HTML puro**, colocando em prática a criação e organização dos elementos de uma página web.

### O que foi feito

* Adicionei o **título principal** da página;
* Coloquei **imagens dos filmes**;
* Adicionei **títulos e descrições** para cada filme;
* Criei **links** para os filmes;
* Organizei os filmes em uma **lista**;
* Adicionei uma parte para **projetar/exibir os vídeos** dos filmes diretamente na página.

### Objetivo

O objetivo desse projeto foi praticar a estrutura básica do **HTML**, aprendendo a trabalhar com textos, imagens, links, listas e vídeos, sem utilizar CSS ou JavaScript.
